# 実行予算の作成 〜 発注承認 業務マニュアル

実行予算をつくってから、業者への見積依頼・選定・承認を経て、発注が承認されるまでの流れをまとめたものです。
「誰が」「どの画面で」「何をすると」「次に誰の番になるか」がわかるように書いています。

---

## 1. はじめに

### 1.1 2つのシステムの使い分け

見積・発注の業務は、**FELIX（従来の管理画面）** と **新見積管理システム** の2つを行き来します。

| | FELIX（従来の管理画面） | 新見積管理システム |
| --- | --- | --- |
| 役割 | **元データをつくる場所**<br/>実行予算・工事項目・見積先（業者）の登録、業者からの見積回答 | **申請と承認をする場所**<br/>見積依頼 → 業者選定 → 部長承認 → 発注承認 |
| 主に使う人 | 建設部の担当者、業者 | 建設部の担当者、建設部部長 |

- FELIX で登録した内容は、**保存した時点で自動的に新見積管理システムへ反映されます**。
  手動での取り込み作業は不要です。
- 新見積管理システムで承認した結果も、**自動的に FELIX 側へ反映されます**。
  どちらか一方だけが更新される、ということはありません（片方が失敗した場合は両方とも取り消されます）。

---

## 2. 全体の流れ

```
【現行Fix】                          【新Fix】

① 実行予算をつくる　────────────▶︎　　・データが表示される
                                    見積依頼画面にて、仮選定を手動設定する()
    見積依頼ファイルをドライブに格納           │
    見積依頼を自動送信(3日に1回)              │
                                  ② 見積依頼画面にて、手動で見積依頼を送る（担当者）
                                    未依頼のみの表示では、表示されなくなる。
                                          │
③ 業者が見積を回答  ◀───依頼メール────────────┘
  (業者マイページ)
        │
        │       見積額のやり取り
        ◀───────────────────────▶︎ ④ 業者選定画面（担当者）◀─────────────────────────────
                                    通常は、選定ボタンが黄色になっている。
                                    仮選定の場合は、業者選定ボタンが緑になっている。
                                    否認された場合は、業者選定ボタンが赤色になっている。
                                    選定すると、その項目は表示されなくなる。(絞り込み制御で)
                                          │                                         │
                                          ▼                                         │
                                  ⑤ 部長承認（部長）────▶︎⑥ 取消申請（担当者）────▶︎⑦ 取消承認（部長）
                                       │      ▲
                                  否認 └──────┘ ④へ差し戻し  選定した業者を変更したい場合は、一度否認してもらう。否認時はのバッヂは、コメントを誰かが開いたバッヂを消すようにする。
                                          │
                                          ▼
                                  ⑧ 自動発注
                                          │
                                          ▼
                                  ⑨ 業者承諾確認────▶︎否認────▶︎発注取消承認────▶︎取消承認────▶︎④業者選定に差し戻す
                                          │
                                          ▼
                                  ⑩ 承認（業者マイページ）
                                          │
                                          ▼
                                  納品管理画面に進む
```

**ポイント**: ②〜⑩は「担当者が申請 → 部長が承認」の繰り返しです。
自分の番が来た件数は、サイドメニューの赤いバッジ（未処理件数）で確認できます。

## 3. 各ステップの操作

### ① 実行予算をつくる（FELIX／建設部担当者）

**場所**: FELIX の実行予算画面

保存した時点で、新見積管理システム側に「物件」「工事項目」「見積先（業者）」が自動でつくられ、見積依頼画面に並びます。

作成後に工事項目や見積先を追加・修正した場合も、保存のたびに自動で反映されます。

> **注意**
> - 新見積管理システムに出てくるのは **建設費用の項目だけ** です。土地原価・金融融資などの
>   項目は対象外なので、見積管理画面には表示されません。
> - **単価や金額を修正したときは、実行予算の画面で保存し直してください。**
>   明細の直接編集だけでは、新見積管理システム側の金額が古いままになります。
> - 工事項目や見積先だけを先に追加しても、実行予算そのものを一度も保存していない物件は
>   新見積管理システムに現れません。まず実行予算を保存してください。

---

### ② 見積依頼を送る（新見積管理システム／担当者）

**画面**: 見積依頼【FELIX→業者依頼前】

業者へ相見積を依頼します。何度でも再依頼できます。

**操作手順**

1. 物件・項目・見積先の絞り込みで対象を探します（物件名／項目名／見積先名の部分一致）。
2. 依頼したい業者の行に **「仮選定」** のチェックを付けます（あくまで目印です。この時点では何も送信されません）。
3. 送りたい行の **「見積依頼」** にチェックを入れます（「全て選択」で一括も可）。
4. 画面上部の **［見積依頼送信］** を押します。

**送信すると**: 業者へ依頼メールが届き、その行の「送信回数」が1増えて「最終依頼日時」が更新されます。

**画面でできること**

| 操作 | 内容 |
| --- | --- |
| 未依頼のみ表示 | まだ一度も依頼していない行だけに絞り込みます（初期表示はON） |
| 仮選定のみ表示 | 仮選定を付けた行だけに絞り込みます |
| 回答状態フィルタ | 業者から見積回答が来ているかどうかで絞り込みます |
| 業者追加 | その項目に見積先を追加します（FELIX の追加画面が開きます） |
| 見積先名をクリック | 見積先の詳細（FELIX の編集画面）が開きます |
| 吹き出しボタン | 項目ごとのやり取り（チャット）を開きます |

---

### ③ 業者が見積を回答する（FELIX 業者マイページ／業者）

業者が依頼メールのリンクからマイページにログインし、金額・明細・見積書ファイルを登録して保存します。

保存されると新見積管理システムに自動で反映され、その見積先が **業者選定画面** に「回答あり」として
現れます。同じ業者が複数回回答した場合は、**最新の回答が有効**として扱われます。

---

### ④ 業者選定（新見積管理システム／担当者）

**画面**: 業者選定【業者→FELIX返答済】

回答が返ってきた見積先の中から、発注する業者を選びます。

**操作手順**

1. 各項目の見積額を見比べ、発注したい業者のボタンを押して **選定** します（押すたびに選び直せます）。
2. 画面上部の **［発注業者を確定］** を押します。

**確定すると**: 部長承認へ進みます。FELIX 側でもその業者が「採用」状態になります。

> **注意**
> - 選定できるのは **見積回答がある行だけ** です。回答がない行のボタンは押せません。
> - 部長承認で否認された行は、この画面に **赤いボタン** で戻ってきます。否認理由はやり取り（チャット）に
>   記録されているので、確認してから選び直してください。同じ項目で別の業者を選定すると緑に変わります。

---

### ⑤ 部長承認（新見積管理システム／部長）

**画面**: 部長承認【業者選定済→FELIX(建設部)】

担当者が確定した業者を、部長が承認します。

**承認する場合**

1. 承認する行の **「承認する」** を押して選択します（「全て承認」で一括も可）。
2. 画面上部の **［部長承認］** を押します。

**否認する場合**

1. 行ごとの **「否認」** を押します。
2. 理由を入力して実行します（**理由は必須**）。

**否認すると**: その見積先は業者選定へ差し戻され、担当者が選び直します。
入力した理由は自動的にやり取り（チャット）へ記録され、担当者に伝わります。

---

### ⑥ 取消申請（新見積管理システム／担当者）

**画面**: 部長取消申請【FELIX(担当者)→FELIX(建設部部長)】

部長承認が済んだ見積先について、担当者が次の段階へ申請します。
**1件ずつ、理由を入力して**実行します（理由は必須。やり取りへ自動記録されます）。

一括処理のボタンはありません。行ごとの「取消申請」ボタンから操作してください。

---

### ⑦ 取消承認（新見積管理システム／部長）

**画面**: 部長取消承認【FELIX(建設部部長)→FELIX(担当者)】

担当者からの申請を部長が承認します。**1件ずつ、理由を入力して**実行します（理由は必須）。

**承認すると**: 見積の承認手続きは完了し、**発注実行**へ進めるようになります。

---

### ⑧ 発注実行（新見積管理システム／担当者）

**画面**: 発注実行【承認済み見積→未発注】

承認が完了した見積のうち、まだ発注していないものを発注します。

**操作手順**

1. 発注する行にチェックを入れます（「全て発注」で一括も可）。
2. **「発注書」** ボタンで、FELIX の発注書内容を確認できます。
3. 画面上部の **［発注を実行］** を押します。

**実行すると**: 発注日が当日で記録され、部長の発注承認待ちになります。

---

### ⑨ 発注承認（新見積管理システム／部長）★ゴール

**画面**: 発注承認【担当者実行済→部長承認待ち】

担当者が実行した発注を、部長が承認します。

**承認する場合**

1. 承認する行の **「承認する」** を押して選択します。
2. 画面上部の **［発注を承認］** を押します。

**否認する場合**

1. 行ごとの **「否認」** を押し、理由を入力して実行します。
2. その発注は取り消され、**発注実行の画面に戻ります**（担当者が発注し直します）。

**承認されると**: 発注が確定し、以降は **業者承諾確認 → 完了確認 → 部長完了承認 → 請求** へ続きます。

---

## 4. やり取り（チャット）機能

すべての画面で、明細の項目名の右にある **吹き出しボタン** からチャットを開けます。

- 担当者と部長が、**工事項目ごと**にやり取りできます（同じ項目に複数の業者があっても1つのスレッドです）。
- 文章のほか、**ファイルを最大5件（1件あたり10MBまで）** 添付できます。画像はサムネイル表示されます。
- **否認・取消申請・取消承認の理由は、自動的にこのスレッドへ記録されます。**
- 未読があると吹き出しに赤い数字が付きます。スレッドを開いた時点で既読になります。
- コメントが1件でもある項目は、吹き出しが金色で強調されます。

「なぜ差し戻されたのか」「どの業者にするか」といった相談は、この機能に集約してください。
