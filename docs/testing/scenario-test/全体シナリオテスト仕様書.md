### 1.2 事前準備

1. 両コンテナが起動していること（`docker ps` に `felix_leasing_app` / `new_fix_dev`）。
2. **DBスナップショットを取る**（テストはデータを書き換えるため）。

```bash
docker exec fix_db sh -c 'mysqldump --default-character-set=utf8mb4 -uroot -proot_password fix \
  $(mysql -uroot -proot_password -N -B -e "SELECT table_name FROM information_schema.tables \
   WHERE table_schema=\"fix\" AND table_name LIKE \"t\\_%\"")' > before_snapshot.sql
```

3. 復元は `docker exec -i fix_db mysql -uroot -proot_password fix < before_snapshot.sql`。
